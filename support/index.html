LittleCanvas Support

Help with drawing, saving your creations, imports, exports and child mode.

Can't draw? / 无法绘画？

Check whether Apple Pencil-only input, a locked layer or a read-only artwork is selected. Switch back to a drawing tool or enable finger input when needed.

请检查是否启用了仅 Apple Pencil 输入、锁定图层或只读作品，并按需切换绘画工具或开启手指绘画。

Save status uncertain? / 保存状态不确定？

Keep the app and your artwork data installed. Use the in-app recovery or verification controls; do not uninstall the app to fix an uncertain save.

请保留应用和原始作品，使用应用内的恢复或检查功能，不要通过卸载应用处理存档问题。

Export or Files problems? / 文件导入导出问题？

Make sure the selected file is supported, the file size is within limits, and permission was granted through Apple's system picker or Files.

请检查支持的文件格式、大小限制，以及系统“文件”App 和照片选取器的授权。

Exiting Child Mode / 退出儿童模式

Use the parent entry point and verify locally with Face ID, Touch ID or your device passcode. LittleCanvas does not receive your biometric data.

请通过家长入口使用 Face ID、Touch ID 或设备密码进行本机验证；小画布不会读取生物识别信息。

Contact & feedback / 联系与反馈

For a technical question, bug report or privacy request, you can open a support issue on GitHub. An account may be required to post. Do not publish a child's private picture, personal contact details or confidential artwork in a public issue.

技术问题和隐私咨询可通过上述 GitHub 支持仓库提交（发帖可能需要账号）。请勿在公开 Issue 中披露儿童照片、联系方式或私人作品。
